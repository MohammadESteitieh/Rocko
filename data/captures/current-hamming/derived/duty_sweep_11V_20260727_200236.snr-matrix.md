## Boundary and timing notes

The initial broad correlation search localized the first frame about 5.36
seconds late and therefore produced invalid frame windows. The regenerated
matrix uses each transmitter manifest `started_utc` boundary plus one common
-0.990-second QNX-to-capture alignment correction estimated from the 100% frame
inside a fixed 1.25-second search radius. The same correction was frozen for all
five frames; no later frame boundary was optimized using its expected payload.

Commanded 1% remained timing-limited: 56 of 112 pulse starts were late, and the
median pulse was 753 us versus the 625 us target. The matrix contains one frame
per duty and is a condition-selection pilot, not a BER confidence estimate.
